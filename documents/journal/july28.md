We started with a review of Agile principles and an introduction to Design Systems. To make my workflow more aligned with Agile, I wrote user stories and updated my Trello board with additional tasks and improvements.

With a clearer vision of my application, I created a relationship diagram in FigJam, defining the models, their properties, and the relationships between them. The diagram shows that one user (the organizer) can create multiple picnics (linked through the user ID), while guests join a picnic using an invitation code.

Based on my user stories, I defined the application's endpoints (pages) and added them to my Trello board as backlog tasks. My next steps are to create wireframes for each page, begin writing the design rationale, and start defining the project's Design System.
